# Source provenance

The shell-free job adapter and workflow derive from [CarstVaartjes/vonk-forge-recipes at 5bbb0be4e604768499ccbcf82bbea181575c31d6](https://github.com/CarstVaartjes/vonk-forge-recipes/tree/5bbb0be4e604768499ccbcf82bbea181575c31d6/adapters/media/comfyui-core). That snapshot supplied no top-level license or adapter copyright/license notice; no broader grant is inferred. Existing source notices and workflow provenance remain intact. Local changes correct executable dispatch and regular-file links inside artifact directory mounts, redirect per-job state, and add offline image checks.

This distinct variant uses the community image `ghcr.io/aeon-7/comfyui-aeon-spark@sha256:7fda74d7af1d86455bfa58df5d36e761964017c7bce6f5d2f3564ba0b2deee3a`. Its image configuration declares Linux ARM64 and CUDA 13.0.2. The actual ComfyUI source identifies [fce0398470fe3ecdb7ab4c5c69555ad0fcbdc09e](https://github.com/Comfy-Org/ComfyUI/tree/fce0398470fe3ecdb7ab4c5c69555ad0fcbdc09e), version 0.20.1. The inspected core CLI, nodes, FLUX nodes, sampler nodes, model management and complete GPL-3.0 LICENSE byte-match that upstream commit. `comfy-source-sha256.json` rechecks those retained image files during our build. ComfyUI's full source and license remain in the base image; no ComfyUI modifications are applied.

The publisher's [147319f950d0f7df981c87755f2a722fbb965a7b](https://github.com/AEON-7/comfyui-aeon-spark/tree/147319f950d0f7df981c87755f2a722fbb965a7b) is the last commit before image creation; its entrypoint byte-matches the image. This is a source reference, not a signed build attestation. The publisher repository declares no aggregate license. No vendor support or aggregate license grant is implied. The image's inherited NVIDIA maintainer label describes its base; it does not establish NVIDIA support for this community assembly.

The installed comfy-kitchen 0.2.8 CUDA extension is ARM64 ELF and byte-matches the official PyPI wheel (wheel SHA256 `0c2eb7d03921a70e21fd9bb43d557e09b20bec81479cb85c2b58e8cdfb2cacc9`, extension SHA256 `11eda3b5bdaec44568fd22d0108aba59c5c1deb4ceef482f3bd5e6e6ee4bd3d9`). Kitchen is Apache-2.0. PyTorch, TorchVision, TorchAudio, Triton, NVIDIA CUDA and other bundled dependencies retain their respective licenses. FLUX.2 Klein 4B NVFP4 and selected encoder/VAE model cards are Apache-2.0; no model files are included in this source bundle.

The Dockerfile clears the publisher startup updater and uses the baked `/opt/venv/bin/python3`. Build network mode is `none` after the normal pinned base image acquisition; there is no package installation or source download. Build checks import the declared dependency versions, run `pip check`, parse the adapter's actual server arguments, and import the selected core node schemas in CPU mode. A bounded receipt remains at `/opt/vonk/runtime-build-checks.json`; these checks do not qualify GPU kernels or generation quality. Runtime disables custom/API nodes and torch.compile, uses explicit per-job SQLite and cache paths, and writes only the final result file into the managed output directory.
