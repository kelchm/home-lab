# Media policy integration after 070

`0710-native-media-preparation-policy.patch` preserves three production behaviors while using 070's bounded CUDA media windows. Apply it after 070. The fixed-detail and video-allocation reference is [production patch 0050](https://github.com/MiaAI-Lab/GLM-5.3-Flash-EXL3-2x-DGX-Sparks-TensorFold/blob/bf5f94523a8251029cedae86bf61f8ce37fac218/patches/0050-glm-many-media.patch).

- GLM keeps its 2,048-token image ceiling when a client sends `detail: low`, as the Python processor does. Other families retain their existing low-detail behavior.
- Each clip receives the lesser of 16,384 tokens and its share of the 32,768-token request budget before planning: 16,384 / 16,384 / 10,922 / 8,192 for one / two / three / four clips. All four large clips can therefore use the configured video capability. Adding clips can change older video grids, as in the production Python policy; the stable 2,048-token image policy is separate.
- The 100-second image and 120-second video budgets account for cumulative active fetch/decode/resize/patchification work. The same request-owned budget follows lazy image/groups, with cancellation checks and charging on errors. Admission waits, unrelated text prefill and GPU tower execution do not expire a valid image before its preparation starts. Cooperative checks still cannot preempt a codec call already in progress.

The earlier 030/070 milestone runners reproduce those historical layers. Their original fixed-video-share and absolute-deadline assertions are superseded by this layer. `tests/run_host.py` installs the final contract cases, forwards checked lazy callbacks in the CPU fixture, and explicitly updates the old four-clip budget assertion to the production reference values. It also runs the actual lane budget test and the recording-CUDA lifecycle tests.

The focused composed run passed 175 tests across 28 build steps, including the API/media/body contract, a synthetic clock exercising long queue/prefill waits and cumulative active work, real video geometry at all four clip counts, shared media budgets, low-detail policy, checkpoint foundations, GLM protocol, KV pages and prompt boundaries. `source-manifest.json` records the five native files and patch identity. This is host/recording-driver evidence. Final artifact compilation, actual codec integration, GPU quality/memory and durable serving remain separate qualification gates.
