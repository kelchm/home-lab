# MetaMCP (retired)

MetaMCP and its PostgreSQL cluster were removed from the cluster configuration in September 2026. Its deployment, route, OIDC client, secrets, network grants, and bootstrap tooling are retired. No registry SQL cleanup is needed.

Use the [MCPHub management guide](../../kubernetes/apps/ai/mcphub/README.md) for the current gateway. The [original rollout plan](../plans/20260620-metamcp-mcp-rollout.md) remains as historical context.
